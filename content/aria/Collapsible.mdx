## Usage

```res showLineNumbers
<Collapsible>
  <Button slot="trigger" variant=Ghost size=Icon>
    <Icons.ChevronsUpDown />
  </Button>
  <Collapsible.Content>
    {"Content here."->React.string}
  </Collapsible.Content>
</Collapsible>
```

## Controlled State

Use `isExpanded` and `onExpandedChange` to control the disclosure state.

```res showLineNumbers
@react.component
let make = () => {
  let (isExpanded, setIsExpanded) = React.useState(() => false)

  <Collapsible isExpanded onExpandedChange={next => setIsExpanded(_ => next)}>
    <Button slot="trigger"> {"Toggle"->React.string} </Button>
    <Collapsible.Content> {"Content"->React.string} </Collapsible.Content>
  </Collapsible>
}
```
