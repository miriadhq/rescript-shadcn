## Installation

Install the [Popover](/components/Popover) and
[Calendar](/components/Calendar) components. Date values use
`@internationalized/date`.

```bash
npx shadcn@latest add @rescript-shadcn/Popover @rescript-shadcn/Calendar
```

## Usage

```res showLineNumbers
module IDate = ReactAria.InternationalizedDate

@react.component
let make = () => {
  let (date, setDate) = React.useState(() => None)

  <Popover.Trigger>
    <Button variant=Outline className="justify-start font-normal">
      {switch date {
      | Some(date) =>
        date
        ->IDate.toDate(IDate.getLocalTimeZone())
        ->Date.toLocaleDateString
        ->React.string
      | None => <span> {"Pick a date"->React.string} </span>
      }}
    </Button>
    <Popover className="w-auto p-0" placement=ReactAria.Common.BottomStart>
      <Calendar value=?date onChange={nextDate => setDate(_ => Some(nextDate))} />
    </Popover>
  </Popover.Trigger>
}
```
