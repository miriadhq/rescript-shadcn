## Usage

React Aria calendars use values from `@internationalized/date` rather than
JavaScript `Date` values.

```res showLineNumbers
module IDate = ReactAria.InternationalizedDate

@react.component
let make = () => {
  let initialDate = IDate.today(IDate.getLocalTimeZone())
  let (date, setDate) = React.useState(() => initialDate)

  <Calendar
    value=date
    onChange={nextDate => setDate(_ => nextDate)}
    className="rounded-lg border"
  />
}
```
