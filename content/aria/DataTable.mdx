## Introduction

Every data table has different columns and behavior, so this is a composition
guide rather than a single `DataTable` component. TanStack Table owns the table
state; `Table`, `Checkbox`, `Button`, `Input`, and `DropdownMenu` render it.

## Installation

```bash
npm install @tanstack/react-table
npx shadcn@latest add @rescript-shadcn/Table @rescript-shadcn/Checkbox @rescript-shadcn/DropdownMenu
```

## Row selection

React Aria checkboxes use `isSelected` and `onChange`.

```res showLineNumbers
let selectionColumn: RT.colDef<payment> = {
  id: "select",
  header: context => {
    let table = context->RT.ctxTable
    <Checkbox
      isSelected={table->RT.getIsAllPageRowsSelected ||
      table->RT.getIsSomePageRowsSelected}
      onChange={next => table->RT.toggleAllPageRowsSelected(next)}
      ariaLabel="Select all"
    />
  },
  cell: context => {
    let row = context->RT.ctxRow
    <Checkbox
      isSelected={row->RT.rowGetIsSelected}
      onChange={next => row->RT.rowToggleSelected(next)}
      ariaLabel="Select row"
    />
  },
  enableSorting: false,
  enableHiding: false,
}
```

## Row actions

Place the trigger button and menu together inside `DropdownMenu.Trigger`.

```res showLineNumbers
<DropdownMenu.Trigger>
  <Button variant=Ghost size=IconXs ariaLabel="Open menu">
    <Icons.MoreHorizontal />
  </Button>
  <DropdownMenu placement=ReactAria.Common.BottomEnd>
    <DropdownMenu.Item onAction={() => copyPaymentId()}>
      {"Copy payment ID"->React.string}
    </DropdownMenu.Item>
    <DropdownMenu.Separator />
    <DropdownMenu.Item> {"View payment details"->React.string} </DropdownMenu.Item>
  </DropdownMenu>
</DropdownMenu.Trigger>
```

## Column visibility

Use one menu with `selectionMode=Multiple`, `selectedKeys`, and
`onSelectionChange`. The regular `DropdownMenu.Item` renders its checkbox
indicator from React Aria's collection selection state.

## Pagination

Use `isDisabled` on the React Aria buttons when TanStack reports that a page is
unavailable.

```res showLineNumbers
<Button
  variant=Outline
  size=Sm
  isDisabled={!table->RT.getCanPreviousPage}
  onPress={_ => table->RT.previousPage()}
>
  {"Previous"->React.string}
</Button>
```

The complete example above includes sorting, filtering, column visibility,
selection, row actions, and pagination.
