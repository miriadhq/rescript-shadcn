## Usage

```res showLineNumbers
<Label htmlFor="email"> {"Your email address"->React.string} </Label>
```

## Label in Field

For form fields, use the [Field](/components/Field) component which
includes built-in `FieldLabel`, `FieldDescription`, and `FieldError` components.

```res showLineNumbers
<Field>
  <Field.Label htmlFor="email"> {"Your email address"->React.string} </Field.Label>
  <Input id="email" />
</Field>
```
