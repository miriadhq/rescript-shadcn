## Installation

```bash
npx shadcn@latest add @rescript-shadcn/Questionnaire
```

For manual installation, install `@shadcn/react@^0.3.1`, `rescript-shadcn-react`, and `cn`, then copy the component and its Button and Icons dependencies.

## Usage

```res
<Questionnaire items=[{name: "task", required: true}] shortcuts=#letters>
  <Questionnaire.Progress />
  <Questionnaire.Item name="task" required=true>
    <Questionnaire.Title> {React.string("What should the agent do?")} </Questionnaire.Title>
    <Questionnaire.Choices>
      <Questionnaire.Choice value="inspect"> {React.string("Inspect the code")} </Questionnaire.Choice>
      <Questionnaire.Choice value="test"> {React.string("Run the tests")} </Questionnaire.Choice>
    </Questionnaire.Choices>
    <Questionnaire.Error />
  </Questionnaire.Item>
  <Questionnaire.Actions>
    <Questionnaire.Submit />
  </Questionnaire.Actions>
</Questionnaire>
```

The root renders a form. Read submitted answers with `FormData` using each item's `name`. Multiple-choice items produce multiple entries under that name. `item` and `onItemChange` control the active question; `defaultItem` selects its initial value. Omit `required` to allow skipping.

Use `Questionnaire.Progress.WithRender` for a callback receiving the primitive's DOM props and `current`, `total`, `first`, and `last` state. Forward those DOM props so accessibility attributes are preserved.
