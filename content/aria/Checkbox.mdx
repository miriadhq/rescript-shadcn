
## Checked State

Use `defaultSelected` for an uncontrolled checkbox, or `isSelected` and
`onChange` to control the state.

```res showLineNumbers
module Example = {
  @react.component
  let make = () => {
    let (isSelected, setIsSelected) = React.useState(() => false)

    <Checkbox isSelected onChange={next => setIsSelected(_ => next)} />
  }
}
```

## Invalid State

Set `aria-invalid` on the checkbox and `data-invalid` on the field wrapper to
